# Triage Labels

工程 skills 使用五种标准 triage 角色。角色名称和 GitHub label 保持英文；面向用户的 issue 评论与说明默认使用简体中文。

| 标准角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及某种 triage 角色时，应用对应的 GitHub label。生成 triage 评论时使用简体中文；代码、命令、文件路径和技术标识符按需保留英文。
